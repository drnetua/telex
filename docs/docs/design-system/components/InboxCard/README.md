# InboxCard

C-11 · The unit of the Inbox: one thing that needs the owner.

- Kinds: draft, needs a check, blocked, note, task due today, draft with a generated image.
- Head: kind badge · assistant · chat · time · C-13 countdown. Body: the original (recessed) and the proposal (`ai-subtle`). One primary action.
- Keyboard: J/K move, Enter approves, E edits, X dismisses. After a decision the card leaves with a short animation (a fade with reduced motion). A decision taken in the Telegram bot updates the card live.
