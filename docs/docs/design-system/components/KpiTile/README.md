# KpiTile

C-38 · One headline number on the Overview: value, change vs the previous period, and a sparkline.

- The change carries an arrow and a word ("better" / "worse"), never colour alone; `better` says which direction is good (spend and errors: `down`).
- The whole tile is a link to the filtered Runs view (SCR-40).
- Empty state for the first day: a dash and "Not enough data yet".
