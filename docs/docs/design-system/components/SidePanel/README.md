# SidePanel

C-05 · Side panel on desktop, full-screen sheet on phone (`layout="phone"`).

- Used for "Why?" (SCR-22), draft editing (SCR-11), tests (SCR-32) and run details (SCR-41).
- Esc or swipe down closes; state survives navigation; the panel has its own URL.
- Consumer provides `title`, `onClose`, content as `children`.
