# Icon

Tabler outline icon drawn inline with `currentColor`. Intentional addition: the primitive every component uses.

- Provide `name` from the Icons asset group and an optional `size` (20 default, 16 inline with `small` text, 24+ for status glyphs).
- Decorative by default (`aria-hidden`); pass `label` when the icon is the only carrier of meaning.
- In the product use `@tabler/icons-react`; the bundle ships only the set teleX uses.
