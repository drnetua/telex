# Cost

C-27 · Money in dollars to the cent, "< $0.01" for tiny amounts, "≈" for estimates; the exact amount is in the tooltip. Tabular figures.

- `precision` (catalog prices): 2 to 4 decimals, trailing zeros trimmed down to cents ("$2.50", "$0.075"), "< $0.0001" below that. The tooltip always holds the exact decimal string.
